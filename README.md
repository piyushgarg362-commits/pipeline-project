# Java Maven Docker Jenkins Project

## Project Description

This project demonstrates a basic CI/CD pipeline using:

- Java
- Maven
- JUnit
- Docker
- Jenkins
- GitHub

## Project Flow

GitHub
→ Jenkins
→ Maven Build
→ Maven Test
→ Docker Build
→ Docker Run

## Requirements

- Java 17
- Maven
- Docker
- Jenkins
- Git

## Build Application

```bash
mvn clean package
